# xuelema Workflows

## 资料库启动

新用户没有资料库时，用 `scripts/init_learning_vault.py --target <dir>` 复制空模板，再运行 `scripts/validate_vault.py --root <dir>`。

资料库根目录至少包含：

- `学习总索引.md`
- `长期记忆/总索引.md`
- `临时文件/待处理`
- `临时文件/待确认`
- `临时文件/处理日志.md`
- 六科目录：`语文`、`数学`、`英语`、`物理`、`化学`、`生物`
- 每科三线目录：`笔记`、`试卷`、`作业改错`
- `周复盘`、`打印版`

## 临时文件

只在用户明确说“放好了”“开始处理”“扫描待处理区”后处理。

1. 运行 `process_inbox.py --root <dir> scan` 查看文件。
2. 先人工判断每个文件的学科、类型、年级、日期和不确定项。
3. 生成 JSON 计划，用 `apply-plan --dry-run` 预览。
4. 用户认可或任务足够明确后，正式 `apply-plan`。
5. 写入 `临时文件/处理日志.md`。
6. 按资料类型启动笔记、作业改错或试卷工作流。

不确定的文件进入 `临时文件/待确认`，不要强行归类。

## 笔记线

1. 保留 OCR 校对稿，标注看不清和待核位置。
2. 生成整理版：先写本节学了什么，再写概念、公式、例题方法。
3. 生成复习卡片：问法短，答案具体，能用于下次抽问。
4. 更新 `长期记忆/笔记追踪.md` 和 `长期记忆/知识点总索引.md`。
5. 同一知识点有不同叫法时，更新 `长期记忆/关键词别名表.md`。

## 作业改错线

1. 先定位错处，不只写“粗心”。
2. 写知识点、错因、正确做法和下次第一步。
3. 能联动课堂笔记时，更新 `长期记忆/错题-笔记联动表.md`。
4. 更新 `长期记忆/作业改错追踪.md` 和 `长期记忆/错因追踪.md`。
5. 反复薄弱或 P0/P1 问题进入 `长期记忆/当前重点看板.md`。

## 试卷线

1. 分开写家长版诊断和学生版反馈。
2. 家长版看趋势：知识点、题型、错因、下周动作。
3. 学生版看执行：本题第一步、正确思路、下次怎么做。
4. 抽 2-4 个高价值薄弱点，不把整张卷子平均用力。
5. 更新 `长期记忆/知识点追踪.md`、`错因追踪.md`、`复盘日志.md`。

## 题库线

题库原卷只存在用户资料库，不进技能仓库。

1. 用 `setup_all_subject_question_banks.py --root <dir>` 建六科题库骨架。
2. 用户自行放入或下载北京高考、北京一模二模、学校卷。
3. PDF 入库后先做文件头和重复校验。
4. 用 `tag_mock_questions_all_subjects.py --root <dir>` 做题号切分和机器初标。
5. 用 `build_ai_question_review_queue.py --root <dir>` 生成 AI 筛题核验队列。
6. 出学生版前，只核最终要用的 3-5 道题：题干、图示/材料、答案、核心知识点。

机器标签只用于筛候选题。未核验题不得进入孩子最终打印版。

## 周复盘和学生打印版

周复盘固定四件套：

1. `家长版周报`
2. `学生打印版`
3. `真题练习`
4. `长期记忆更新`

学生打印版必须做到：

- 本周学了什么讲清楚，孩子不翻书也能看懂核心知识点。
- 本周错了什么讲具体，避免只写“注意审题”。
- 哪些需要加强要有排序，最多抓 2-4 个重点。
- 加强动作要能执行：先做什么、写哪几行、用什么题验证。
- 真题练习默认来自本地题库中的已核验真题或原卷。
- 公式、符号、图示按 `print-and-formula.md` 核验。

## 长期记忆

新增记录时，尽量同时写清：

1. `掌握状态`：待观察、薄弱、反复薄弱、基本掌握、已改善。
2. `证据状态`：原图待核、OCR待校、老师批改、人工核验、机器初标。
3. `下次验证`：下一次用哪类题、哪份作业或哪次小测验证。
4. `优先级`：P0/P1/P2；P0/P1 进入当前重点看板。

历史沉淀放追踪表，最近 2-4 周真正要盯的内容放 `当前重点看板.md`。

## 初中复用

初中可复用同一套结构：资料进入、三线归档、长期记忆、阶段复盘。

调整点：

- 年级目录改为 `初一上`、`初一下`、`初二上`、`初二下`、`初三上`、`初三下`。
- 题源改为本地校内卷、北京中考真题、区级模拟题或用户自建题库。
- 不默认使用高考题和高三一模二模。
- 学科可按用户需要增删，不强制高中六科。
