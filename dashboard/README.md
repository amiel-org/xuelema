# 学了么学情看板（通用模块）

这是学了么的**只读展示层**：将已复核的目标、证据、复盘与任务记录组织成家长能看懂的界面，不替代资料处理和学情审核。

## 启动

在项目根目录执行：

```powershell
python dashboard/server.py
```

浏览器打开 `http://127.0.0.1:8765/`。默认加载 `sample-data.json`，其中所有学生、证据、复盘、题录与任务均为**虚构演示**，无需数据库或第三方服务。

```powershell
# 使用其他端口，不自动打开浏览器
python dashboard/server.py --port 8766 --no-browser

# 加载按同一结构准备的个人数据
python dashboard/server.py --data "D:\私人目录\dashboard-data.json"

# 只校验数据，不启动服务
python dashboard/validate_data.py dashboard/sample-data.json
```

## 已实现

- 六科首页：当前少量重点、下一步行动和已评估目标的基本掌握比例。
- 统一目标图谱：按学科与证据状态筛选，展开原始证据和题录关系。
- 题录索引：学科、年份筛选，多选和浏览器打印。
- 周/月复盘：实际周期、交付日期、摘要、来源和限制。
- 执行任务：区分完成、待复核、进行中和需介入。
- 桌面/手机响应式布局；仅监听 `127.0.0.1`；静态资源白名单；无远程跟踪。

## 数据边界

- 通用模块只读，**不接受 POST，不直接修改学情，不发布题库或学生练习**。
- `linked` 表示待复核关系，不是孩子已接触或已掌握；`none` 表示暂无证据，不是不会。
- 基本掌握比例默认以已评估目标为分母，不能把真题目录当完整教材目录。
- 个人接入应从正式发布的结构化记录生成 JSON，并核验来源；真实个人数据不要放入本仓库。
- 题录与图片要接入本地资料时，应通过个人适配器提供。本通用包不包含真实真题、学校材料或私人链接。

## 数据结构

见 `sample-data.json`。顶层包含：

- `meta`：展示名称、学期、复盘周期与提示。
- `locks`：四个发布/学情锁必须为 `false`，防止看板冒充正式发布。
- `subjects`：六科摘要及当前行动。
- `targets`：目标、证据状态、证据数组和题录ID。
- `records`：题录及目标关联；演示包内为虚构条目。
- `reviews`：实际复盘元数据。
- `tasks`：真实任务状态的可视化摘要。

可用 `dashboard/validate_data.py` 检查ID唯一性、学科关联、题录引用及四锁。结构校验通过不证明学情判断正确；原始证据仍须走学了么审核与发布流程。
