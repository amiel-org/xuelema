# 练习题源与核验规范

本文件是正式练习题源与核验的权威规范。诊断/进度证据见学习判断与证据规范，文件内容与排版见学生打印版规范。

## 默认来源与授权

正式练习、针对性训练、周自测、小测、巩固题、变式题默认从本地已归档原题选取：

1. 北京高考原题。
2. 北京东城、西城、海淀、朝阳等已入库一模二模原题。
3. 已归档、能核题干与可靠答案的学校卷、教辅或校内同类原题。

周复盘的每个本周重点必须至少配置一道与该弱项匹配、逐题核验过的北京高考原题或条件完整的原题节选。卡片、校内旧题、一模二模题和 `practice_limits` 不能替代这道北京高考题；它们可以作为补充。即使本周没有明确强化重点，整份周打印版也至少配置一道按本周知识点或历史待验证弱项选出的北京高考原题或完整节选，整周不得为零。题目难度或后续知识不适配时，优先选基础小问或保留完整条件的节选，不能为了凑题让孩子做未学内容。

非周重点练习仍按上述检索优先级执行。家长提供的当前原题可优先回做。概念提取卡可以整理已有笔记，不得包装成高考真题。

非重点科目没有可靠适配原题时，可以减少数量或暂缓并保存实际检索及限制记录。重点科目检索不到适配北京高考原题时，不得用卡片或题源限制替代后宣称周打印版完成；应缩小重点、继续核原卷，或明确报告该重点尚不能正式发布。不默认自编或改编；只有用户已有明确允许时才使用，并逐题标注“改编题”及授权依据，不能伪装为原题。

## 从学习目标选题

先确定本次知识点、确认错处/待验证能力、题型、必要前置知识和难度。每题必须能回答：解决哪个具体问题，为什么适合现在，预计多久，下次如何判断有进步。

| 适配情况 | 处理 |
|---|---|
| 已学可练 | 可用完整原题，难度与本次能力目标相称 |
| 刚学入门 | 优先基础原题或完整保留必要条件的原题节选 |
| 当前资料未能确认已学 | 查任务、实际进度或必要说明；未确认前不把综合题列为必做 |
| 已确认未学/超出当前范围 | 家长记录后续安排，暂缓正式综合训练；已授权预习可做前置铺垫 |

同一关键词不证明前置知识都已学；题源来自高三也不代表每个小问都超出当前范围。节选明确题号和小问，保留原题所需条件，禁止自行补写缺失条件却标原题。

## 逐题核验

| 项目 | 必须留下的依据 |
|---|---|
| 原题来源 | 本地原卷/原图、文件指纹、年份地区考试科目题号或教辅页码、页/区域定位 |
| 题干 | 对照原始资料确认完整，不直接使用机器切分或OCR占位片段 |
| 图示/材料 | 必要图、表、实验装置、结构、流程、长文本全部保留或准确重绘 |
| 标准答案 | 单独标可靠答案出处及页/题号；AI推断不能标成已核标准答案 |
| 公式符号 | 分式、上下标、向量、单位、化学式、离子电荷、反应箭头正确 |
| 进度与目标 | 关联本次证据、实际已学前置知识及选题目的 |
| 学生/答案隔离 | 学生题面不夹答案、解析、直接泄题提示；答案版独立 |

由AI执行对照时写“AI对照原卷/答案”，不能记作人工或老师核验。机器索引、队列、旧报告的“已核验”文字不能替代本次所用版本的核对。核验对象变化后重新检查。

## 输出

学生版放来源、题干和必要材料、作答区、不泄题的要求及与本次问题的简短联系；不放原始文件路径、核验管理字段。答案版放标准答案、必要步骤、讲评、原题/答案出处和核验限制。

内部运行清单记录 source、answer_source、source_category、finding_ids、learning_level、prerequisite_evidence、figure_required/figure_paths、学生与答案产物、minutes 和 required。weekly 重点题的 source_category 必须为 `beijing_gaokao`。具体字段见技能 references/run-contract.md。

题量与必做学科数服从当前看板/本次用户目标。宁可少量有效原题，也不凑每科固定数量。减少或暂缓的原因明确进入家长说明。
