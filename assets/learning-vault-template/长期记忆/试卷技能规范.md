# 试卷诊断规范

本文件负责试卷处理；证据与状态按学习判断与证据规范，题源按练习题源与核验规范，交付按执行与验收规范和学生打印版规范。学习建档说明只作入口，不再覆盖专项规则。

## 输入与完整性

记录科目、年级、原卷日期（可未知）、归档日期、地区/考试类型、题号和页数范围、是否含答题卡/标准答案。先确认是否完整；缺页、模糊、答案不齐分别登记，不能补造。

拆分印刷题干、孩子原始作答、订正、来源可确认的老师批改与来源不明批注。保留题图/材料及证据位置。OCR 是草稿，决定对错和选题时回原图/原卷。

## 逐题诊断

1. 对照题干、图示、可见作答和可靠答案，区分正确、错误、未答、待核；有过程则检查步骤，不能只看最后数字。
2. 对每个确认错误记知识点、实际错处与证据。错因候选包括概念、审题、模型识别、图像理解、公式条件、计算、步骤和表达；未知时保留待验证。
3. 回查已有笔记/作业，区分当前学过、刚入门、进度未确认和明确未学；不得把索引没记录直接等同没学过。
4. 保留正确及部分正确表现；同题重拍归于同一事件，不能累计为反复错误。
5. 能核算的分数才写确认值。局部资料不能推算全卷分数、排名或班级相对位置。

## 反馈与训练

- 家长版：本次证据范围、主要表现、少量高价值目标、下一步和待核限制。
- 学生反馈：具体问题、相关概念/方法、下次第一步，语气具体有分寸。不要用“粗心、态度差”代替证据。
- 训练：针对本次目标筛适配的已核验原题/节选；标准答案、图/材料、条件、符号必须回查。找不到可靠题源时写清检索结果，减量或暂缓。
- 学生正式打印版与答案分文件；练习不能只留题号或只给概念卡冒充正式原题。概念卡可作热身。
- 下次验证：明确题目/能力、独立完成条件、是否需要提示、何时复查；没有后续结果时不预先标已改善。

## 记录字段

每个判断至少有：科目、知识点、原材料位置与题号、可见事实、解释/待验证项、掌握状态、优先级、下次验证。运行清单需要的结构见技能 references/run-contract.md；不能只填“已核验”而无原始位置和对照记录。

## 更新与验收

更新试卷索引、知识点追踪、错因追踪和复盘日志；按证据决定联动表、知识点总索引与当前重点看板是否变化。没有新学情时说明原因。

交付检查：输入和题号范围无漏项、确认错误可回原图、学科推理正确、训练进度适配、题图与标准答案完整、学生与答案分离、正式文档逐页可用、记忆更新有依据。运行程序通过后再发布，规则与学科审核不能互相替代。
