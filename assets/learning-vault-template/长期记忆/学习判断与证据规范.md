# 学习判断与证据规范

生效：2026-09-12。用于所有学情判断、题目适配和长期状态更新；本文件统一这些规则，其他规范引用。

## 先记录事实，再判断

每条重要观察写清：科目、知识点、原始资料位置/题号、可见作答或原话、证据类型、实际作答日期（未知就未知）、独立学习事件。归档日期不代表作答先后；同页重拍属于同一事件。

区分三层：

1. 事实：原图能看到什么，能核对哪些答案、步骤或批改。
2. 解释：根据事实可能是哪类困难；解释须说明依据，不能补造孩子心理、习惯或课堂经历。
3. 验证：下一次用什么小任务区分这些可能，怎样算独立通过。

证据来源按实际标注“原图已核/原图待核、OCR待校、AI对照原卷、家长确认、老师批改（来源已确认）”等。AI审核不记为人工或老师审核；红笔来源不明就写来源不明。机器标签只服务检索。

## 禁止错误推断

- 笔记/索引无记录 → 当前资料未见已学证据；不能直接认定没学过。需结合课堂任务、学校进度或孩子/家长说明。
- 笔记出现 → 有学习接触证据；不能直接认定掌握或能迁移。
- 有红笔、留白、短答 → 先核作答与批注；不能直接认定该题错误、孩子不会或粗心。
- 重拍、局部照片、同题多个版本 → 同一事件；不能用照片数量制造“反复错误”。
- 完成订正、抄了正确答案、有提示做对 → 记录该次表现；不能直接升级“已改善/基本掌握”。
- 学期路线图、教材常见安排、历史薄弱点 → 只作计划或检索线索；不能代替当前证据或挤占本周全部重点。

## 掌握状态与证据

| 状态 | 可接受依据 | 后续动作 |
|---|---|---|
| 待观察 | 已见相关内容，但对错、错因或独立完成情况未充分确认 | 安排一个短验证；不强贴薄弱标签 |
| 薄弱 | 至少一处与该知识点有关、已核实的错误或独立作答障碍 | 先补最小必要知识/方法，再回做 |
| 反复薄弱 | 同一知识点至少两个独立学习事件中有确认错误；同页重拍不计 | 提高优先级，分析前次干预为何未通过 |
| 已改善 | 有相对旧问题的独立正确作答证据；无直接答案/步骤提示，非仅订正 | 标注改善证据和仍待迁移/保持的部分，减少重复训练 |
| 基本掌握 | 默认需不同时间、至少两次独立通过，覆盖目标能力；一次做对不足以确认稳定 | 转低频跟踪，后续出现反例再调整 |

这些是家庭记录的保守口径，不是科学测量分数。一次题目无法证明整章掌握；状态只覆盖有证据的具体知识点/能力。错误原因未知时可确认“本题错”，但错因保持待验证。

保留正确表现，尤其是“同类一对一错”；这能帮助区分概念缺失与条件变化后的应用困难。历史记录不批量改状态，新证据用时间、来源和理由增量关联。

## 年级与实际进度

先从本周原始笔记/任务和已确认说明建立实际进度，再选题。已学前置知识可核对时用整题；刚入门用基础原题/完整节选；尚无已学证据的先做进度确认或前置铺垫；已确认未学的暂缓综合训练。

“明确超纲/未学”也需要依据，不能仅因题源来自高三就一律排除；同时不能因为标签含本周关键词就忽略题目需要后续模块。

## 优先级、负担与有效性

- 优先处理当前最影响理解/得分且已有证据的问题；本周通常只抓少量重点。历史问题有本周验证必要时才进入当前任务。
- 本次必做用时和最多学科数从当前看板/用户要求确定。完整归档、覆盖全部知识点，不等于要求孩子做完全部科目和题目。
- 每个训练说明对应哪个问题、为什么适合现在、预计用时、遇到困难先做哪一步。无可靠题源可减量，不凑数。
- 先独立尝试；卡住时给最小必要提示，再区分独立完成与提示后完成。不要强迫无意义重复抄写或每题画同一种图。
- 根据下一次实际结果调整：当次通过、仍卡住、提示后通过、待验证。适时再用独立同类题检查保持与迁移；材料生成多、排版漂亮、孩子抄满不作为学习效果指标。
- 家长默认只提供资料和已有表现；不要求家长代替AI筛题、做资料覆盖检查或审核文件结构。学校进度和孩子独立完成情况确实无法从材料判断时，再询问必要事实。
