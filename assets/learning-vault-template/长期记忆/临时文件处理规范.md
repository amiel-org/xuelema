# 临时文件处理规范

> 2026-09-12执行接入：任务登记、续接和正式验收统一按 `执行与验收规范.md`；学情判断按 `学习判断与证据规范.md`。本文件只规定分拣与归档。先只读扫描/识别本批，登记完整输入与实际资料类型，再移动；原始范围清单不能因移动而丢失。`triage` 可做轻量 OCR/视觉摘要和预索引，但不替代后续深度学习处理。

## 触发语

当用户说：

- 处理临时文件
- 今天上传好了
- 按流程处理新照片
- 把临时文件分一下

默认按本规范执行。

## 入口目录

用户只需要把新照片放入：

```text
<资料库根目录>\临时文件\待处理
```

不要求用户提前区分学科，也不要求提前区分笔记、作业、试卷。

识别不确定的文件放入：

```text
<资料库根目录>\临时文件\待确认
```

## 分拣时允许的识别深度

`triage` 不是只看文件名后搬运文件。模型应先逐张/逐组查看原图；清晰图片可直接用视觉读取，文字密集或不确定时再做局部、轻量 OCR。OCR 是识别手段，不要求在这一步产出逐字校对稿。

分拣阶段应尽量建立页级/组级预索引，至少记录：

- 学科、资料类型和识别置信度；
- 同一资料组、页序、重复/重拍关系；
- 标题、日期、章节、题号范围和可见关键词；
- 可从页面看出的候选主题（标为“候选”，不当作最终知识点清单）；
- 清晰度、缺页/局部拍摄等完整性风险；
- 是否存在学生作答、订正或批注（只记录“存在”，不判断对错和来源）；
- 下一步路由：`notes`、`homework`、`exam` 或待确认，以及仍需核对的具体位置。

这些线索写入本批分拣预索引和任务记录，处理日志保留可供周末查找的简表。若学科和类型已经可靠确定，只是个别文字看不清，可以先正常归档并标“内容待核”；只有路由本身不确定或图片无法可靠读取时才放入待确认。

分拣阶段可以识别“这是什么、涉及什么、下一步去哪”，不能完成“孩子这题对不对、为什么错、掌握到什么程度”。完整 OCR 校对、逐题判错、错因诊断、复习卡片、练习和长期状态更新分别留给后续流程。

## 默认年级与日期

- 当前默认年级：高一下，适用到 2026-08-31。
- 日期按“处理当天日期”建立文件夹，不按照片拍摄日期、微信文件名日期或卷面日期。
- 上述日期只是归档日期。原卷日期、实际作答日期另记；未知不推测，不据归档日期累计独立错误次数。
- 从 2026-09-01 起，默认进入高二上。
- 后续按自然学期自动增长：

```text
2026-05-09 至 2026-08-31：高一下
2026-09-01 至 2027-02-28：高二上
2027-03-01 至 2027-08-31：高二下
2027-09-01 至 2028-02-29：高三上
2028-03-01 起：高三下
```

- 每年 9 月 1 日升到下一年级上学期。
- 每年 3 月 1 日切到本年级下学期。
- 如果用户提醒学校节奏特殊，以用户提醒为准。
- 在 8 月底、9 月初、2 月底、3 月初等临界日期附近，如果归档量较大或材料标题与默认年级冲突，要主动提示用户确认。

## 移动规则

处理成功后，文件从 `待处理` 移动到正式目录，不复制，不额外备份，不删除。

正式目录：

```text
<资料库根目录>\<学科>\笔记\<年级>\<当天日期>\
<资料库根目录>\<学科>\作业改错\<年级>\<当天日期>\
<资料库根目录>\<学科>\试卷\<年级>\<当天日期>\
```

示例：

```text
<资料库根目录>\语文\笔记\高一下\5.10\
<资料库根目录>\数学\作业改错\高一下\5.10\
<资料库根目录>\物理\试卷\高一下\5.10\
```

### 同名文件防覆盖

移动文件时不得覆盖正式目录中的已有文件。

如果目标目录已经存在同名文件，自动在文件名后追加序号：

```text
原文件名.jpg
原文件名_重复1.jpg
原文件名_重复2.jpg
```

如果同名文件内容明显是同一张照片，也仍然不覆盖，先保留为 `_重复N`，后续需要清理时再单独处理。

## 学科识别

按照片内容判断学科，优先看：

- 题头、页眉、教材名、章节名
- 关键词和符号
- 题型特征
- 批注内容和老师标记

常见识别线索：

| 学科 | 线索 |
|---|---|
| 语文 | 课文名、现代文/古文、作文、阅读题、人物形象、情节作用 |
| 数学 | 函数、向量、三角、立体几何、证明、坐标、公式推导 |
| 英语 | 英文文章、语法、词汇、应用文、阅读理解、完形填空 |
| 物理 | 速度、加速度、力、功、能、圆周、抛体、图像、实验 |
| 化学 | 化学式、离子、方程式、实验流程、有机物、元素化合物 |
| 生物 | DNA、RNA、蛋白质、遗传、细胞、生态、实验表格 |

## 类型识别

### 笔记

手写课堂页、板书摘录、知识整理、答题框架、复习卡片草稿，优先判断为笔记。

典型特征：

- 手写为主。
- 有课文、知识点、公式、流程、方法总结。
- 不是完整题组或正式卷面。

### 试卷

正式考试、测验、月考、期中、期末、检测卷、诊断卷等，判断为试卷。

典型特征：

- 有标题：月考、期中、期末、测试、试卷、诊断、检测。
- 有总分、时间、班级、姓名、密封线、答题区。
- 题号连续较多，题型结构完整。
- 有分数、扣分或老师批改痕迹。
- 来源像学校统一印发材料。

### 作业改错

练习册、课本练习、专题训练、课后题、日常改错，判断为作业改错。

典型特征：

- 有页码或练习册栏目，例如基础巩固练、综合提升练、课后练习、专题课。
- 题量可能只有一页或几道题。
- 没有完整考试标题、总分、考试时间。
- 有订正、批改痕迹，但更像日常练习。

## 易混规则

最重要原则：

```text
宁可把疑似作业按作业处理，不轻易当试卷。
```

原因：

- 试卷工作流更重，会做完整诊断、错因、学生反馈和长期追踪。
- 作业工作流更轻，适合日常练习和改错。
- 如果后续确认它其实是试卷，可以再移动升级处理。

具体判断：

| 情况 | 默认处理 |
|---|---|
| 周测/月考/期中/检测卷，有考试信息 | 试卷 |
| 练习册基础巩固练/综合提升练 | 作业改错 |
| 学校发的专题训练但没有分数、时间、完整考试结构 | 作业改错 |
| 有完整考试信息、总分、时间、答题卡结构 | 试卷 |
| 手写课堂页 | 笔记 |
| 看不清学科或类型 | 待确认 |

## 待确认规则

以下情况不要硬归档，移动到 `<资料库根目录>\临时文件\待确认`：

- 看不出学科或资料类型，导致路由无法确定。
- 图片无法可靠读取，连标题/题型/页序等基本线索也无法判断。
- 同一组照片可能跨学科或跨类型。
- 文件移动后可能覆盖已有同名文件且无法安全改名。

放入待确认的文件必须在处理日志中写明原因，不能只写“待确认”。

常见说明：

```text
只拍到局部，看不出学科
照片模糊，看不清题头
像专题训练，但无法判断是否完整试卷
同一组照片疑似跨学科
```

## 日志

每次处理后更新：

```text
<资料库根目录>\临时文件\处理日志.md
```

处理日志只作为当天临时查看，不做长期留存。

规则：

- 每次开始处理新批次前，如果上一批已经处理完成，先清空 `处理日志.md` 并重写表头。
- 当天用户查看完、确认无需保留后，可以清空，只保留表头。
- 不把历史批次长期追加在这个文件里，避免越积越多。
- 长期趋势、错因和知识点沉淀进入 `长期记忆` 里的对应文件，不依赖临时处理日志。

记录字段：

```markdown
| 批次 | 处理日期 | 原始文件 | 识别学科 | 识别类型 | 目标位置 | 状态 | 说明 |
|---|---|---|---|---|---|---|---|
```

如果 `处理日志.md` 不存在，先创建文件并写入表头。

### 批次编号

每次处理 `待处理` 目录时生成一个批次编号，格式：

```text
YYYY-MM-DD-第N批
```

示例：

```text
2026-05-10-第1批
2026-05-10-第2批
```

当天如果多次处理临时文件，批次号递增。批次号写入处理日志和当次处理小结，方便以后追踪“这一批照片去了哪里”。

## 大批量处理规则

如果 `待处理` 中一次超过 30 张照片，默认先执行“分拣优先”：

1. 先识别学科、类型、同组关系、页序、基本内容线索和清晰度；必要时做轻量 OCR。
2. 先移动到正式目录或待确认目录。
3. 先生成处理日志和分拣小结。
4. 再按科目和类型逐步启动笔记、作业改错、试卷工作流。

大批量时不要一边识别一边深度诊断，避免混科、缺页、重复照片或模糊照片影响后续处理。

分拣小结可以写入：

```text
<资料库根目录>\临时文件\处理日志.md
```

或在当次回复中简要说明：

```text
本批共 X 张：语文笔记 X 张，数学作业 X 张，物理试卷 X 张，待确认 X 张。
```

## 每日处理完成小结

每次处理完成后，回复用户时使用固定小结格式：

```text
本批：YYYY-MM-DD-第N批
共 X 张
已归档：语文笔记 X 张，数学作业 X 张，物理试卷 X 张……
待确认：X 张
学习处理：笔记 X 组完成，作业 X 组完成，试卷 X 组完成；未完成 X 组及原因
待处理目录：已清空/仍有 X 张
```

如果有待确认文件，必须说明待确认原因和所在目录。

## 后续工作流

移动完成后，根据类型启动对应工作流：

| 类型 | 后续处理 |
|---|---|
| 笔记 | OCR校对稿、整理版、复习卡片、笔记索引、长期记忆 |
| 作业改错 | 作业改错诊断、作业改错索引、作业追踪、错题-笔记联动 |
| 试卷 | 试卷诊断、家长版/学生版反馈、错因追踪、知识点追踪、复盘日志 |

处理完成后，`待处理` 目录应为空；无法判断的文件只留在 `待确认`。

上述清空仅针对已登记本批。处理中后来新增的文件另开批次或明确追加范围，不能为了清空目录擅自处理新范围。每组的实际产物、待核项与后续流程记入本批运行清单，验收通过后才说明本批已交付。
