# 三线联动学习闭环

生效规则：本文件只负责三线关联和更新；证据、状态、进度判断统一执行 [学习判断与证据规范.md](学习判断与证据规范.md)，任务与交付执行 [执行与验收规范.md](执行与验收规范.md)。

## 三条线分工

| 资料 | 主要回答 | 本次产物 | 更新去向 |
|---|---|---|---|
| 笔记 | 接触、记录过什么 | OCR校对稿、知识整理、复习卡片 | 笔记索引、笔记追踪、知识点总索引 |
| 作业改错 | 哪一步出现已确认错误或障碍 | 改错诊断、正确做法、下次第一步、复习卡片 | 作业索引、作业改错追踪、错因追踪 |
| 试卷 | 在何种条件下能否独立完成 | 逐题核对、家长诊断、学生反馈、少量练习/验证安排 | 试卷索引、知识点追踪、错因追踪、复盘日志 |

三线按资料类型存放，通过统一知识点名称与独立学习事件关联，不互相替代。笔记出现不证明掌握；同页重拍不制造多次错误。

## 联动顺序

1. 查知识点总索引和必要的关键词别名，优先复用已有名称。
2. 查该科该学期笔记、作业、试卷索引，回到相关原始材料。
3. 分开已有事实与待验证判断，写清来源、日期、题号/页码和事件。
4. 当有可核对关系时更新错题-笔记联动表；无需为每条笔记虚构一个错点。
5. 更新追踪记录；有当前跟进价值时更新当前重点看板，其他历史信息留在追踪表。

## 从证据选择动作

| 观察 | 处理 |
|---|---|
| 未见已学证据 | 标待确认，查课堂任务/学校进度；不能直接写没学过 |
| 刚学入门，尚无稳定独立表现 | 先确认概念入口，用适配的基础原题或完整节选验证 |
| 能确认学过，但复述或默写出现错误 | 找具体概念条件，做少量提取练习 |
| 概念能说对，条件变化后应用失误 | 用已学同类原题检查条件识别和解题入口 |
| 同类一对一错 | 同时保留正确例，核比较条件，避免归为整章不会 |
| 两次独立学习事件出现同类确认错误 | 考虑反复薄弱，查前次干预与后续验证结果 |
| 仅完成订正或需提示 | 记录当次表现，另待独立验证 |

## 周复盘覆盖

先核本周三线资料和索引，形成知识点全集，再决定重点。每项输入均对应整理/诊断及知识点；每个知识点标“重点展开、简要保留、待核/暂缓”及去向。不能只依据上一次周摘要生成新打印版。

重点优先看已确认反复错误、学过但应用困难和当前易遗忘的核心内容。来源数量本身不等于优先级，同一页三个重拍只算一条学习证据。未重点展开的知识点保留简短清单；不要把所有知识点都变成必做任务。

训练调用和适配执行练习题源与核验规范；正式输出执行学生打印版规范。题源不足、未确认进度或材料缺失时记录限制，不自编凑数。

## 最低更新

- 笔记：学科/学期笔记索引、笔记追踪、知识点总索引；别名新增才更新关键词别名表。
- 作业：学科/学期作业索引、作业改错追踪、错因追踪；有证据关联才更新错题-笔记联动表。
- 试卷：学科/学期试卷索引、知识点追踪、错因追踪、复盘日志；有新联动才更新联动表。
- 每次处理均检查当前重点看板：有新增有效证据则更新；没有则说明维持原因，不制造变化。
- 新状态必须可回查原材料；旧记录保留历史，新证据纠正旧结论时说明理由，不批量重写历史画像。

运行清单中的更新前指纹用于防止覆盖其他任务的新记录；拟更新文件先放本批 staged，验收后发布。
