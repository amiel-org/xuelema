# 学习总索引

这是学习资料库的总入口。先读本文件与 `长期记忆/总索引.md`，再按任务读取专项规范；实际学情必须回原始资料。

## 执行入口

- 固定入口：根目录 `AGENTS.md`、`长期记忆/执行与验收规范.md`。
- 学情、进度与负担：`长期记忆/学习判断与证据规范.md`。
- 维护源、安装版本与学期入口：`长期记忆/学了么配置.json`。
- 处理/诊断/打印任务登记在 `任务记录/`；查询讨论可只读，不自动生成整套交付。

## 资料线

- 笔记、作业改错、试卷分开存，通过知识点和独立学习事件联动。
- 临时文件只做入口；学生打印版与周复盘单独存。
- 原始材料不覆盖；正式学生件与答案件分开，发布前必须验收。
